# ❌⭕ Tic Tac Toe (C++ Console Game)

A simple two-player Tic Tac Toe game built using C++ and developed in Code::Blocks. This project demonstrates core programming concepts such as arrays, functions, loops, and conditional logic.

---

## 📌 Overview

This is a console-based Tic Tac Toe game where two players take turns marking positions on a 3×3 grid. The game checks for winning conditions after each move and declares the winner or a draw.

---

## 🎮 Features

* Two-player gameplay (X and O)
* Interactive console interface
* Input validation for invalid moves
* Automatic win and draw detection
* Clean and simple game logic

---

## 🧠 Concepts Used

* 2D Arrays
* Functions
* Loops (`for`)
* Conditional statements (`if-else`)
* User input handling (`cin`, `cout`)

## ▶️ How to Run

### Using Code::Blocks

1. Open Code::Blocks
2. Open the project or `main.cpp` file
3. Press **F9 (Build and Run)**

---

### Using Terminal (Optional)

```bash
g++ main.cpp -o game
./game.exe
```

---

## 🎯 How to Play

* The board is numbered from 1 to 9:

```
1 2 3
4 5 6
7 8 9
```

* Players take turns entering a position number
* Player X goes first
* First player to align 3 marks (row/column/diagonal) wins
